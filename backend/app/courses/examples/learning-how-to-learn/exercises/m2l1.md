## Problem

Pick one real thing you're learning right now (a concept, a skill, a chapter). Design a
**four-touch spaced schedule** for it using expanding intervals, and decide what you'll *do* at
each touch (it must be retrieval, not re-reading).

Before reading the solution, write down:

1. Your four review dates, starting today.
2. For each touch, the retrieval action (e.g. "blank-page recall", "self-quiz", "redo a problem").
3. One way you'll **interleave** it with a related topic at touch 3 or 4.

## Solution

A worked version for "Spaced repetition" itself, started on a Monday:

1. **Touch 1 — Mon (today):** close the notes; write the definition + why spacing beats cramming,
   from memory.
2. **Touch 2 — Wed (+2 days):** self-quiz — "What's an expanding-interval schedule? When does
   interleaving hurt?"
3. **Touch 3 — next Mon (+1 week):** blank-page recall of the *whole* module so far, interleaved
   with retrieval practice.
4. **Touch 4 — +3 weeks:** redo this exercise for a brand-new topic, mixing in the older material.

What makes it correct: the **gaps expand** (2 days → 1 week → 3 weeks), every touch is
**retrieval** (producing from memory, then checking), and touch 3 **interleaves** rather than
re-blocking the same idea. If your plan used fixed daily intervals or "re-read the notes," revise
it — those are the two most common ways this goes wrong.
