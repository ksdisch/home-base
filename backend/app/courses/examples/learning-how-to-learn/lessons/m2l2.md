# Retrieval Practice & Elaboration

This lesson ties the course together into something you can run every week.

## Retrieval practice (testing as studying)

The act of trying to recall information *is* one of the most powerful ways to learn it — the
**testing effect**. A low-stakes quiz isn't just measurement; it's a learning event, often more
effective than an equal amount of re-studying.

How to run it:

1. Close the book. From memory, write everything you can about the topic.
2. *Then* open the book and check — fill gaps, correct errors.
3. The gaps you found are exactly what to review next.

Free recall (blank page) and self-quizzing both work. The key is producing answers **before**
looking.

## Elaboration (asking "why")

**Elaborative interrogation** means asking *why* a fact is true and *how* it connects to what
you already know. "Why would spacing beat cramming?" forces you to build explanatory links,
which give memory more retrieval routes.

A related move is **self-explanation**: narrate your reasoning as you work through a problem,
explaining each step to yourself.

## A weekly study loop

Putting the whole course together:

1. **Encode** new material once (read/watch) — don't over-invest here.
2. **Retrieve** it the same day from a blank page.
3. **Space** reviews on expanding intervals.
4. **Interleave** related topics in each session.
5. **Elaborate** — ask why and connect to prior knowledge.

That loop, run consistently, beats many more hours of re-reading. Take the check below from
memory first — that's retrieval practice in action.
