## Problem

Reproduce a Wilson score interval by hand (or in a 5-line script), then interpret it.

1. For the `forge-gap` baseline arm `27/40` (p = 0.675, n = 40), compute the Wilson 95% interval. Confirm it is about `[52.0, 79.9]`.
2. Now do a boundary arm, `0/40`. Compute the Wilson 95% *upper* bound, and note what the naive `p ± 1.96·√(p(1−p)/n)` gives instead.
3. In one sentence each: why is the `27/40` interval not centered on 67.5%, and why does the `0/40` case show Wilson earning its keep?

## Solution

The Wilson center and half-width use `z = 1.96` and `n = 40`:

```
center = (p + z^2/(2n)) / (1 + z^2/n)
half   = ( z * sqrt( p(1-p)/n + z^2/(4n^2) ) ) / (1 + z^2/n)
```

1. For p = 0.675, n = 40: center is about 0.664 and half is about 0.139, giving roughly `[0.525, 0.803]`, i.e. about `[52.5, 80.3]` — matching the repo's `[52.0, 79.9]` to rounding. It sits *below* 67.5 because Wilson shrinks toward 0.5 at finite N — an honesty correction, not an error.
2. For `0/40`: p = 0. The naive interval gives `0 ± 0` — zero width, "provably 0%," which is nonsense from 40 trials. Wilson gives a positive upper bound of about `z^2 / (n + z^2)` = `3.84 / 43.84` = about `0.088`, i.e. an upper bound near **8.8%**. That "≤ ~9%" is exactly the kind of bound `decay-pin` reports for its `0/40` pinned arm.
3. `27/40`: finite-N shrinkage toward 0.5. `0/40`: the naive bound is a zero-width lie; Wilson gives the honest "consistent with anything up to ~9%," which is what you actually know.

If you reached for `p ± 1.96·√(p(1−p)/n)` on the `0/40` arm and got `0 ± 0`, that is the whole reason the portfolio never uses it.
