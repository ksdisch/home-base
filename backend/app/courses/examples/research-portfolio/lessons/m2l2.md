## The chart, and the honest caption

On an *injected* transient tool fault, an error-recovery guardrail takes GLM-4.6 from **67.5% to 100%** (27/40 to 40/40), a +32.5 pp gap with Newcombe `[+17.3, +48.0]`. The chart says "injected" on it. Then, because the strong model had *no natural gap*, you pivoted to weaker models and found **natural** gaps closed by different guardrails.

## The four guardrails and their failure classes

Each guardrail targets one mechanical failure:

- **error-recovery** — a transient tool fault (a 503) the model must recover from.
- **retry-nudge** — a malformed tool call that should be retried.
- **submit-nudge** — the model never submits a final answer.
- **validation** — the model answers without checking the evidence it retrieved.

Know which failure each fixes; a common probe is "name the four and what each catches."

## Injected vs natural — the distinction the project lives on

- **Injected gap:** you seed a deterministic 503 fault to *create* a recovery scenario, at a disclosed rate. It is a controlled fault-recovery testbed, not a claim about GLM-4.6's real-world failure rate.
- **Natural gap:** a weaker model genuinely fails unaided (e.g. llama-8b `0/40` to `18/40`, +45 pp), and a guardrail closes it.

The ablation rig measures each guardrail *in isolation* and stacked, so a gap is attributable to one mechanism.

## Validation's blind spot (say it before you are asked)

The validation guardrail reads only the run's *own* tool results — it is self-consistency, not an answer key. So it can accept a self-consistent-but-wrong retrieval; you quantify this (about 10% of llama-8b misses). Disclosing the hole is what keeps it judge-free and honest.

## ⚠️ Common mistakes

- **Presenting the 67.5 to 100 gap without "injected."** If a skeptic has to extract it from you, the whole chart looks like a trick. Lead with it.
- **Claiming the paper's gap reproduces naturally on GLM-4.6.** It does not, and you never claim it does — that is why the caveat is load-bearing.
- **Implying validation is an oracle.** It is self-consistency; name the ~10% it wrongly accepts.
