The crux to nail is *matched budget* — it is the single idea that rules out the lazy dismissal "source-first just kept more text." Everything else follows from getting that one right.

## The claim: a lossy note can be worse than empty

For agent memory, a *lossy* compression can be worse than keeping nothing. If a note keeps the wrong *conclusion* but drops the *source* you would recompute from, the error welds in — a later correction cannot reach it. Keep the source and the same model stays fixable, at the *same budget*.

## Matched budget and the four policies

- **Matched memory budget** — both notes are the *same length*; the only difference is *what* they keep. This is the whole point; it rules out "source-first just kept more."
- **lossy** — keep the conclusion, drop the source.
- **source-first** — keep the source, drop the conclusion.
- **padded** — lossy padded to source-first's length. The content-vs-length control: it is *longer* and still walls, proving it is *what* you keep, not *how much*.
- **blank** — empty memory.

**Reclaim Rate (RR)** = the fraction of drifted problems a correction recovers, scored by exact match.

## "Worse than empty" — the behavioral core

Blank memory makes the model *abstain*; lossy memory makes it emit a *confident wrong* value.
